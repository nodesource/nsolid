Deep runtime-level observability for Node.js applications.

N|Solid Runtime is an open-source, cross-platform JavaScript runtime based on Node.js and developed by NodeSource. It captures detailed performance, security, and diagnostic data directly from the Node.js runtime, giving developers and DevOps teams the runtime evidence they need to diagnose production issues, analyze application performance, identify security risks, and understand application behavior.

N|Solid Runtime is the best way to capture detailed runtime-level observability data for Node.js applications and turn that data into the evidence needed to find, diagnose, and resolve issues faster.

## Runtime-Native Observability

Because observability is built directly into the runtime, N|Solid Runtime captures detailed Node.js signals and diagnostics, including:

* CPU and memory telemetry
* Event loop metrics
* CPU profiles and heap snapshots
* Application performance insights
* Package and security intelligence
* Runtime diagnostics for production troubleshooting

This runtime-level visibility gives developers the evidence they need to understand why an application is failing, slowing down, consuming unexpected resources, or behaving unexpectedly.

### N|Solid DevTools

N|Solid DevTools bring N|Solid Runtime intelligence directly into developer and AI-assisted workflows through the N|Solid Extension and N|Solid Plugin.

#### N|Solid Extension

Bring N|Solid Runtime observability directly into your code editor. Explore runtime telemetry, diagnostics, dependency information, performance insights, security data, and AI-assisted workflows without leaving your development environment.

**Install the Extension:**

* [Visual Studio Code Marketplace](https://marketplace.visualstudio.com/items?itemName=nodesource-inc.nsolid)
* [Cursor, Windsurf & Antigravity](https://marketplace.windsurf.com/extension/nodesource-inc/nsolid)

#### N|Solid Plugin

Bring N|Solid Runtime capabilities into supported AI coding agent workflows. Give agents access to runtime telemetry, CPU profiles, heap snapshots, vulnerability analysis, dependency audits, benchmarks, and other Node.js diagnostics to investigate and resolve issues using runtime evidence.

**Get the Plugin:**

* [GitHub](https://github.com/nodesource/nsolid-plugin)
